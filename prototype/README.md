# PlayPro Interactive Prototype 2.0

This directory is an isolated UI/UX prototype track, built on branch `feat/playpro-prototype-2.0`.

## Safety boundary
- No production database writes.
- No production authentication or API secrets.
- Use synthetic fixture/profile data only.
- Do not merge this branch or deploy to the production alias without explicit approval.
- Prototype hosting must use a separate Vercel project or isolated Preview configuration.
